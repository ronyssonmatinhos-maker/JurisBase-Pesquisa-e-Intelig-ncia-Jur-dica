# JurisBase-Pesquisa-e-Intelig-ncia-Jur-dica
Leis, precedentes, julgados e fontes oficiais em um só lugar.

## MVP

Aplicação estática para pesquisar um catálogo demonstrativo de legislação federal. A pesquisa e os filtros são executados localmente no navegador; cada resultado aponta para a fonte oficial no Planalto.

## Executar

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Testes

Requer Node.js 18 ou superior. Execute `npm test` para verificar normalização, validação, pesquisa e filtros.

O catálogo inicial está em `src/data.js`. O conteúdo é demonstrativo: consulte a fonte oficial para confirmar o texto vigente e sua aplicação ao caso concreto.
